# 🏨 Hotel Booking App (iOS)

An iOS Hotel Booking application built using **Swift** and **SwiftUI**, showcasing modern iOS development practices.  
The app demonstrates hotel search, room details, reviews, and maps integration. Currently, it works with mock data and is designed to highlight various Swift and SwiftUI functionalities.  

---

## ✨ Features

- 📄 **Home Screen** – Displays hotels with details  
- 🛏️ **Room Page** – Shows available rooms with prices and details  
- 📖 **Detail Page** – Complete hotel description with images  
- ⭐ **Review Page** – Displays customer reviews (mock data)  
- 🗺️ **MapKit Integration** – Shows hotel locations on a map  
- 🎨 Built using **SwiftUI** showcasing animations, navigation, and bindings


 ## 🛠️ Tech Stack  

- **Swift**  
- **SwiftUI**  
- **MapKit**  
- **Xcode** (minimum version 15 recommended)
